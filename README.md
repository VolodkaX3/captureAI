# Screenshot AI (без API-ключа)

Нажимаешь горячую клавишу → появляется маленькая панель → жмёшь
«Захватить экран» → скриншот сразу копируется в буфер обмена → жмёшь
«Открыть Claude.ai» (или Gemini) → вставляешь картинку в чат (Ctrl+V)
и пишешь свой вопрос вручную.

Никакого API-ключа и оплаты — всё через обычный бесплатный чат в
браузере. Автоматический ответ ИИ прямо в панели в этой версии
недоступен (для этого как раз и нужен был API-ключ) — зато не платишь
ни копейки.

## Установка (в VS Code)

1. Открой папку `screenshot-ai-free` в VS Code.
2. Открой терминал (Ctrl+`) и поставь зависимости:
   ```
   npm install
   ```
3. Запусти приложение:
   ```
   npm start
   ```

## Использование

- **Ctrl+Shift+Space** — открыть/закрыть панель (работает в любом окне).
- Кнопка **«Захватить экран»** — делает скриншот и сразу копирует его
  в буфер обмена.
- Кнопка **«Открыть Claude.ai»** или **«Открыть Gemini»** — открывает
  соответствующий чат в браузере по умолчанию.
- В открывшемся чате нажми **Ctrl+V**, чтобы вставить скриншот, и
  напиши свой вопрос.
- **Esc** или крестик — закрыть панель.

## Как это устроено

- `globalShortcut.register` — системная горячая клавиша, работает вне
  фокуса приложения.
- `desktopCapturer.getSources` — делает снимок экрана.
- `clipboard.writeImage` — кладёт картинку в системный буфер обмена
  (как обычный Ctrl+C со скриншота).
- `shell.openExternal` — открывает сайт в браузере по умолчанию.

## Если позже захочешь автоматический ответ ИИ прямо в панели

Это и есть версия с API-ключом (`screenshot-ai`, которую делали
раньше) — там скриншот сразу уходит в Claude и ответ появляется в
самой панели, без переключения в браузер. Отличие только в стоимости:
там нужен платный (хоть и очень дешёвый) API-ключ.
